## 1. 目的・背景

東京近郊の日帰り旅行は、行き先の候補が多い一方、営業時間・移動時間・昼食を考えながら 1 日の行程を組むのが手間になる。
本アプリは「机の上に紙の地図を広げて計画する」体験を通じて、行き先選びから実現可能な 1 日の行程づくりまでを 1 画面で完結させる。

## 2. 対象ユーザー・利用シーン

- 対象: 東京近郊への日帰り旅行を計画する個人旅行者(主に韓国語話者)
- 利用シーン: 旅行前に PC / スマートフォンで行程を作り、Google マップ・Google カレンダーに持ち出して当日使う
- 前提: アカウント登録・ログイン・API キーは不要

## 3. スコープ

### 3.1 対象範囲(In)

- 東京都・神奈川県・千葉県・埼玉県の 18 エリアのスポット選択と日帰り行程の作成
- 行程の最適化・提案・営業時間チェック
- Google マップ / マイマップ / カレンダーへの持ち出し
- 静的ホスティング(GitHub Pages)での公開

### 3.2 対象外(Out)

- 宿泊を伴う複数日の行程
- 公式時刻表・運賃・乗換案内(移動時間は距離からの推定)
- ユーザーアカウント、行程の保存・共有、サーバー側の処理
- 予約・決済
- 上記 4 都県以外のエリア

## 5. データ要件

| 区分 | 内容 |
| --- | --- |
| エリア | `id`、都県、日本語名/韓国語名、行政区域コード、キャッチコピー、駅、スポット、移動時間の上書き(`transit`) |
| スポット | 座標、標準滞在時間(分)、営業時間(開館/閉館)、カテゴリ(神社・寺・自然・食・眺望・散策・博物館・遊び)、優先度(1 定番 / 2 おすすめ / 3 穴場)、説明 |
| 地図データ | 東日本の都県境界、4 都県の市区町村境界(GeoJSON、簡略化済み) |
| 写真 | スポットごとに 1 枚(現在 85 枚)。作者・ライセンス・出典 URL を `photo-credits.json` に保持 |
| 保存 | サーバー・DB なし。状態はブラウザのメモリ上のみ(リロードで初期化) |

## 6. 非機能要件

| 区分 | 要件 |
| --- | --- |
| 配信 | 静的エクスポート(`output: "export"`)で GitHub Pages に配信できること。サブパス対応(`BASE_PATH`) |
| 外部通信 | 地図タイル(OpenStreetMap)のみ。API キー・自前サーバーは使わない |
| 対応環境 | 最新の主要ブラウザ(WebGL 対応)。PC とスマートフォン |
| 性能 | 地図の遷移アニメーションが滑らかに動くこと。日程計算は選択スポット 8 件以下で全探索、それ以上は最近傍法+2-opt |
| 品質 | 日程計算・Google マップ URL 解析・KML/ICS 生成は Vitest で単体テストする(現在 38 件) |
| ライセンス | 写真は CC BY / CC BY-SA / CC0 / パブリックドメインのみ。OSM の帰属表示と利用ポリシーを守る |
| 保守性 | 地名・スポットは `data/regions.ts` に集約し、コードを触らずに追加できること |
| 個人情報 | 個人情報は扱わない。入力された URL・座標はブラウザ内で解析し送信しない |

## 7. 制約・前提

- 移動時間は距離からの推定(徒歩 4.5km/h、電車 22km/h + 待ち 8 分、徒歩は 1.2km 以内)。実際の時刻表とは異なる
- スポットの座標・営業時間・滞在時間は公開情報をもとにした目安で、定休日・臨時休業は考慮しない
- 機能の一部(実際の地図)は OpenStreetMap のタイル配信に依存する
